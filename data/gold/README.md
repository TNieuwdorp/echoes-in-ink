# Gold transcriptions

One `.txt` per page, named after the image file stem (`1945-03-15_p1.txt` for
`1945-03-15_p1.jpg`) or after the `page_id`. Lines starting with `#` are comments.
`[?]` marks an illegible word, `[gecensureerd]` a censored span.

`holdout.txt` lists stems that are never used as few-shot examples so the benchmark
stays honest.

The two `1945-03-15_*` files were transcribed by Claude from the sample photos while
setting up the project. Treat them as provisional until a family member has checked
them against the originals; doubtful words are listed at the top of each file.
